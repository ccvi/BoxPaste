BoxPaste 使用帮助

常驻菜单栏的剪贴板历史工具 · 版本 1.0.27

它是什么

BoxPaste 在你复制任何内容时默默记一条，需要时按 ⇧⌘V 呼出面板挑回来。默认不占 Dock，启动后看菜单栏多出来的剪贴板图标。

文本、链接、图片、文件都能记；图片支持大图预览与 OCR 取字。

三分钟上手

  1. 在任意应用里按 ⇧⌘V 呼出面板（键位可在「设置 → 快捷键」改）。
  2. 上下键挑一条，↩ 或双击直接粘贴；点面板外面或按 Esc 收起。
  3. 想先看看全文/大图，选中后按 空格：会在屏幕中央弹出一个 800×500 的独立预览窗，再按 空格 或 Esc 收起。
  4. 左键点菜单栏图标也能开面板；右键是菜单（暂停记录、记录富文本、设置、退出）。
首次粘贴没有自动替你按 ⌘V？说明还没给「辅助功能」授权。到「设置 → 通用 → 自动粘贴」点「打开系统设置」勾上 BoxPaste 即可；未授权时功能自动降级为「内容已复制，你自己按 ⌘V」，不会报错。

批量粘贴

  • 怎么用：按住 ⌘ 点选多条（或按 ⌘A 全选），工具条上点「粘贴」。
  • 效果：按列表显示顺序，一条接一条粘到刚才那个应用里，每条之间隔 0.25 秒（间隔太短目标应用会丢条目）。
  • 中止：粘贴过程中再按一次呼出热键把面板叫出来，剩下的就不再粘了。
  • 前提：需要「自动粘贴」和辅助功能授权（跟单条粘贴一样）；没开的话只会复制第一条，并在面板上提示原因。

分类、收藏与置顶

  • 顶栏是分类：全部 / 收藏 / 链接 / 图片 / 文件，后面可以自建分类并配规则（按类型、来源应用、包含文本、正则）。
  • 收藏是手动归类：条目右键 →「移到分类」→ 收藏。清空历史时收藏永远保留。
  • 置顶的条目不会被条数上限淘汰，清空历史时也可以选择保留。
  • 保留期（设置 → 通用 → 最长保存时间）可选 30/45/60/90 天或不限：到期自动清除更早的记录，收藏的永远保留。默认不限。

隐私：不想被记下的内容

  • 暂停记录：菜单栏右键 →「暂停记录」。这期间的复制完全不进历史，图标会变成暂停样式；再点「恢复记录」继续。重启应用默认恢复记录。
  • 记录富文本：菜单栏右键可开关。开着时从网页/Word 复制的内容会保留格式，粘贴回去不变纯文本；关掉只留纯文字，也不占额外空间。
  • 复制为纯文本：文本条目右键的这项，只把纯文字放进剪贴板——要贴进代码或终端时用。
  • 密码管理器等标记为「保密/临时」的剪贴板内容默认就不记录（可在设置里关掉这条保护）。

数据与备份

历史都在本机，不上传任何地方：

  • ~/Library/Application Support/BoxPaste/history.json —— 条目元数据
  • …/blobs/ —— 图片原图与缩略图、富文本存档

换机器或重装前，用「设置 → 关于 → 导出历史」存一份 JSON；新机器导入即可（重复内容自动跳过）。

常见问题

  • 菜单栏图标不见了？先退出再重开一次；仍不行就检查「系统设置 → 菜单栏」里 BoxPaste 的开关是否打开。
  • 粘贴后面板没收起 / 没自动粘贴？看设置里「自动粘贴」是否开启、辅助功能是否授权；日志在 /tmp/boxpaste-paste-debug.txt。
  • 图片条目显示「图片已不可用」？原图文件被外部删掉了，删掉这条重新复制即可。
  • 预览里内容显示不全？超大内容（超过 200 行或 2 万字符）预览只显示开头，是为了不让面板卡死；完整内容照常可以粘贴，或用预览底部的「复制」拿走全部。
  • 菜单栏图标偶尔闪一下、像"重启"了？这是内存回收：占用达到 250MB 且空闲 30 秒时，BoxPaste 会自己重开一次，把用久了的界面内存还给系统。规则是 30 分钟内最多一次、24 小时内连续 3 次后自动停用；你手动退出再打开等于重新计数。剪贴板历史不会丢（重启前会先落盘，重启后还会把当前剪贴板补收一条）。
  • 想要更多提示音？把音频文件放进 ~/Library/Sounds 后告诉我，可以接进音色选择器。
